# Lirena font history

## 0.300 / v0.3.0 — 2026-10-04

The independent adaptation is renamed from Instrument Serif Cyrillic to Lirena.
Both styles have updated family, full, PostScript and unique names, version and
description metadata. Distributed filenames and web CSS use Lirena.
Glyph outlines, metrics, hinting and OpenType shaping tables are unchanged.
The original Instrument Serif Latin design is retained. Bulgarian Cyrillic forms
remain the existing adaptation, with source forms from Cormorant Garamond.
Original copyright notices and both OFL 1.1 license texts are preserved.
Cyrillic adaptation by Stiliyan Spasov / Spasov Type.

## 0.200 / v0.2.0 — 2026-10-03

Published as Instrument Serif Cyrillic, with Regular and true Italic in TTF and
WOFF2 formats, the adaptation scripts, source fonts, credits and OFL licenses.
